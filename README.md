OOUUH AI's Original Motion mode is based on the Oouuh kitchen reference associated with that phrase. You make the video in your browser from two portraits; no CapCut template, separate editing app or recorded performance is needed.

### Can I make it from a single photo?

Original Motion requires two individual portraits. A single photo showing both people is supported in Original mode, which creates a new song. A photo of only one person is not enough for either two-person performance.

### Does the video keep the original Fredo Bang Oouuh audio?

Original Motion uses the original audio from the 15-second reference clip. Original mode creates new AI vocals and ukulele music. Uploading a photo does not clone the person's real voice.
